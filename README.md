# Bloste-Software

Plataforma intermodular de gestión de contenido multimedia que integra un catálogo de productos, un servidor de medios, un módulo de autenticación JWT con Odoo y aplicaciones web y móvil.

## 📋 Estructura del Proyecto

### Backend

- **Catálogo**: Servicio de gestión de productos (Spring Boot)
- **Media Server**: Servidor de almacenamiento y procesamiento de videos (ExpressJS)
- **Odoo Módulos**: Módulos personalizados de Odoo para autenticación y gestión

### Frontend

- **Admin**: Panel de administración web (Vue.js)
- **BlosteFlix**: Aplicación móvil de reproducción de contenido (Flutter)
- **BlosteWeb**: Aplicación de suscripciones (Odoo)

## 📝 Requisitos

- Docker y Docker Compose
- Java 11+ (Catálogo)
- Node.js 16+ (Media Server)
- Flutter 3.0+ (Aplicación móvil)
- Odoo 16+ (Backend de módulos)
